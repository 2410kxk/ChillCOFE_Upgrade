# Nguồn kiểm tra đã thực hiện

Các tệp ở đây là bản lưu nguồn của test host và kiểm tra HTTP đã chạy trong môi trường Linux của Codex. Chúng dùng SQLite và dữ liệu giả lập riêng, có tài khoản thử cố định; không phải thông tin đăng nhập của ứng dụng giao cho nhóm. Đường dẫn trong script là đường dẫn môi trường kiểm tra, không phải lệnh chạy sẵn trên Windows. Không chép test host vào src và không triển khai nó. Kết quả máy đọc: ../integration-results.json.

Nhóm kiểm thử trên SQL Server bằng bảng thao tác ở ../KIEM_THU_VA_MINH_CHUNG.md.
